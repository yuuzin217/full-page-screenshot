# フルページスクリーンショット（Chrome拡張）

ページ全体（スクロールしないと見えない部分まで）を、つなぎ目なしで1枚のPNG画像に保存する拡張機能です。

## インストール手順

1. このフォルダ（または zip を解凍したフォルダ）を Mac の分かりやすい場所に置く
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」を ON
4. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダを選ぶ
5. ツールバーにカメラのアイコンが出れば完了（ピン留めすると便利です）

## 使い方

1. 撮影したいページを開く
2. 拡張のアイコンをクリック
3. 「ページ全体を撮影」を押す → 既定ではダウンロード＋結果が別タブで開きます
   - 「表示中の画面だけ撮影」も選べます
   - ポップアップ内のチェックで「別タブで開く」「自動でダウンロードする」をそれぞれ切り替えられます（設定は保存されます）
   - 別タブの結果画面には画像サイズ表示とダウンロードボタンがあり、画像は24時間だけ拡張内に一時保存されます

## 仕組みと注意

- 撮影には Chrome のデバッガ機能（Page.captureScreenshot）を使い、ページをスクロールして貼り合わせる方式ではないため、固定ヘッダーが何度も写ったり、つなぎ目がずれたりしません
- 撮影中、一瞬だけ「"フルページスクリーンショット" がこのブラウザのデバッグを開始しました」という帯が表示されます。撮影が終われば自動で消えます
- とても長いページでは、Chrome の画像サイズ上限（16,384px）に合わせて自動で縮小します
- `chrome://` などのブラウザ内部ページと、Chrome ウェブストアのページでは撮影できません（Chrome の制限です）
- 権限は `activeTab`、`debugger`、`storage`（チェック設定の保存用）のみ。今開いているタブに対して、アイコンを押したときだけ動作します
